# Amazing Grace Book Reader

Native Android app scaffolded with Kotlin and Jetpack Compose.

## Included core features
- Gallery image selection for screenshot OCR input
- ML Kit text recognition service (`OcrManager`)
- Android TextToSpeech wrapper with play/pause/stop controls (`TtsManager`)
- Compose-based UI in `MainActivity`

## Project layout
- `app/src/main/java/com/amazinggrace/bookreader/MainActivity.kt`
- `app/src/main/java/com/amazinggrace/bookreader/OcrManager.kt`
- `app/src/main/java/com/amazinggrace/bookreader/TtsManager.kt`
- `app/src/main/AndroidManifest.xml`
- `app/build.gradle.kts`
